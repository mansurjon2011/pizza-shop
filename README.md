# Сайт доставки пиццы (Node.js + SQLite + Payme + Click)

Что умеет сайт:
- меню с категориями, размерами и добавками, корзина (сохраняется в браузере), промокоды;
- оформление заказа: доставка или самовывоз, оплата наличными, **Payme** или **Click**;
- страница статуса заказа (принят → готовится → в пути → выдан), обновляется сама;
- админка `/admin.html`: заказы и смена статусов, редактирование меню, добавок и промокодов;
- уведомления о заказах в Telegram (по желанию).

Все цены и суммы считаются **на сервере** по базе данных. Подделать цену через браузер нельзя.

## 1. Запуск у себя на компьютере (проверка)

Нужен Node.js версии 20 или новее (https://nodejs.org).

```bash
npm install
cp .env.example .env        # на Windows: copy .env.example .env
npm run hash -- "МойПароль123"   # скопируйте выданную строку ADMIN_PASSWORD_HASH=... в .env
npm start
```

В файле `.env` задайте также `JWT_SECRET` (любая случайная строка от 32 символов).
Откройте http://localhost:3000. Админка: http://localhost:3000/admin.html (логин из `ADMIN_USER`, по умолчанию `admin`).

Пока в `.env` стоит `DEMO_PAYMENTS=true`, при заказе доступна кнопка «Демо-оплата» без денег. Так можно проверить весь путь: меню → корзина → заказ → оплата → статус → админка.

## 2. Telegram-уведомления (по желанию)

1. В Telegram создайте бота у @BotFather, получите токен → `TELEGRAM_BOT_TOKEN`.
2. Напишите боту любое сообщение (или добавьте его в группу), узнайте ID чата (например, через @userinfobot) → `TELEGRAM_CHAT_ID`.
3. Токен хранится только на сервере в `.env`, в браузер он не попадает.

## 3. Подключение Payme

1. Зарегистрируйтесь в Payme Business, подайте заявку на подключение интернет-эквайринга (потребуется юрлицо или ИП).
2. В кабинете создайте кассу. Получите **Merchant ID** и **ключ** (отдельные для тестового и боевого режима).
3. В настройках кассы укажите:
   - адрес Merchant API (Endpoint URL): `https://ВАШ-САЙТ/api/payme`
   - поле счёта (account): `order_id`
4. В `.env`: `PAYME_MERCHANT_ID`, `PAYME_KEY`, `PAYME_TEST=true`.
5. В кабинете есть тестовая песочница Payme: пройдите её проверки. Только после этого переключите `PAYME_TEST=false` и впишите боевой ключ.

Суммы в Payme передаются в тийинах (сумы × 100), сайт это учитывает сам.

## 4. Подключение Click

1. Подключитесь к Click Merchant по схеме **Shop API**. Вы получите `service_id`, `merchant_id` и секретный ключ.
2. В кабинете Click укажите адреса:
   - Prepare URL: `https://ВАШ-САЙТ/api/click/prepare`
   - Complete URL: `https://ВАШ-САЙТ/api/click/complete`
3. В `.env`: `CLICK_SERVICE_ID`, `CLICK_MERCHANT_ID`, `CLICK_SECRET_KEY`.

Способ оплаты появляется на сайте автоматически, когда заполнены ключи.

## 5. Выкладка в интернет

Нужен сервер с постоянным адресом и **HTTPS** (Payme и Click не работают с обычным http): например, VPS (Ubuntu) + домен.

```bash
npm install --omit=dev
npm install -g pm2
pm2 start server.js --name pizza && pm2 save && pm2 startup
```

Перед сервером поставьте nginx или Caddy с сертификатом Let's Encrypt, проксируйте на порт 3000. В `.env` укажите `SITE_URL=https://ВАШ-САЙТ`.

**Перед приёмом настоящих денег проверьте:**
- `DEMO_PAYMENTS=false` (иначе любой сможет «оплатить» заказ кнопкой без денег!);
- `PAYME_TEST=false` и боевые ключи;
- задан длинный `JWT_SECRET` и сильный пароль админа;
- файл `.env` никому не передавался;
- регулярно копируйте файл `data/pizza.db` (там все заказы).

## Важно знать

- Возврат денег за оплаченный заказ делается в кабинете Payme/Click. Отмена заказа в админке саму оплату не возвращает.
- Фото блюд: в админке вставляйте ссылки на картинки (https://…). Без фото показывается значок категории.
- Код платёжных частей написан по документации Payme и Click и проверен имитацией их запросов, но с вашими реальными ключами я его проверить не мог. Обязательно пройдите тесты в кабинетах Payme и Click до запуска.
